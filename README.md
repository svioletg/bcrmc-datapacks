# bcrmc-datapacks

Datapacks and resource packs for personal servers. OGG files for jukebox songs are not included
in this repository.

See [Releases](https://github.com/svioletg/bcrmc-datapacks/releases) for downloads.

## Versioning

Releases from 2026-09-24 onward are in the format YYYY.MM.DD+mcversion: the date the release was
cut, and the Minecraft version it targets/is last confirmed to work with.
